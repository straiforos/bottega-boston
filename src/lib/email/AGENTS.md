# Email

- Pasta Club emails: staff edit validated Bottega blocks, which `src/lib/email/render-email.ts` converts to a Waypoint (`@usewaypoint/email-builder`) document and renders for both preview and send; the editor UI is Bottega components (never the MUI Waypoint editor); sending goes through Resend server-side only, staff functions re-check has_role, Resend events arrive at a Svix-verified `/api/public/resend-webhook`, scheduled sends run via cron at `/api/public/send-scheduled`, and other flows send via `sendTemplate` with `{{field}}` fill-ins; email colors are literal copies of Bottega tokens — why: preview equals inbox, no client path can send, and email clients can't read CSS variables.
- The footer's postal addresses ship as explicit anchors styled `mustardDeep` with `text-decoration:none` (never bare text) — why: mail clients auto-linkify bare addresses in their own blue underline, and an anchor we own keeps the brand color.
