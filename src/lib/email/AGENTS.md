# Email

- Pasta Club emails: staff edit validated Bottega blocks, which `src/lib/email/render-email.ts` converts to a Waypoint (`@usewaypoint/email-builder`) document and renders for both preview and send; the editor UI is Bottega components (never the MUI Waypoint editor); sending goes through the Resend API server-side only (`RESEND_API_KEY`), staff functions require the staff session cookie, Resend events arrive at a Svix-verified `/api/public/resend-webhook`, scheduled sends run via Wrangler cron and the `CRON_SECRET`-gated `/api/public/send-scheduled` route, and other flows send via `sendTemplate` with `{{field}}` fill-ins; relative in-site paths are absolutized at send time; email colors are literal copies of Bottega tokens, because preview equals inbox, no client path can send, and email clients can't read CSS variables.
- The footer's postal addresses ship as explicit anchors styled `mustardDeep` with `text-decoration:none` (never bare text), because mail clients auto-linkify bare addresses in their own blue underline, and an anchor we own keeps the brand color.
- The staff canvas renders with `editor: true` (block anchors + a sandboxed selection script that only posts geometry/events); sends never pass it, and a test asserts sent HTML has no editor markup, because overlays stay Bottega components in the parent while the iframe stays the exact inbox HTML.
